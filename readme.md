# 🎬 Movie Booking App

A full-stack Movie Booking Application where users can browse movies, check show timings, and book tickets easily.

---

## 🚀 Features

- 🎥 Browse available movies
- 🏢 View theatres and show timings
- 🎟️ Book movie tickets
- ❌ Cancel bookings
- 🔐 User authentication (Login / Register)
- 🛠️ Admin panel to manage movies & theatres

---

## 🛠️ Tech Stack

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)

**Frontend (if any):**
- React.js / HTML / CSS / JavaScript

**Tools:**
- Postman (API Testing)
- Git & GitHub
